# easpOS

A calm personal workspace for planning, focus, and everyday progress.

## Step 1 — Project foundation

This version sets up React, TypeScript, Vite, Tailwind CSS, a responsive dark glass-inspired application shell, and client-side routes for Dashboard, Tasks, Goals, Habits, Calendar, Notes, Focus Timer, and Insights. Feature modules are intentionally placeholders for the next implementation steps.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The build script runs the TypeScript checker before generating the Vite production bundle.
